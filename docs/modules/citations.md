# Citations vérifiables

Chaque citation contient les identifiants de source, version et chunk, le document ouvrable dans la bibliothèque, les pages et la section lorsqu'elles sont connues, l'extrait exact, le score et le rang. Le validateur refuse une source supprimée, une version qui n'est plus active et tout extrait absent du chunk persisté.

Une réponse documentaire n'est produite que si toutes les preuves retenues donnent une citation valide. Les affirmations retournées référencent explicitement leurs identifiants de citation.
